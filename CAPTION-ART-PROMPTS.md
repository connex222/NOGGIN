# Caption This — picture prompts for Creative Claw

Caption This works much better with a picture to caption. Make the pictures with Creative Claw, save each one with the file name shown, and upload them to `public/art/captions/` on GitHub. The game uses a picture automatically when its file exists; once 10 or more scenes have pictures, Caption This only uses pictured scenes.

**Paste this once at the start (style guide):**

```
Create a series of comedy illustrations for a family TV party game called NOGGIN. Style: bright, glossy 3D cartoon caricatures like a modern animated film, big expressive faces, exaggerated poses, warm studio lighting, simple uncluttered background, landscape 16:9, no text, no logos, no speech bubbles. Keep each named character consistent with the reference portrait I attach for them. Each picture should show a funny moment that people can write a caption for.
```

**Then for each picture:** attach the character portraits from `public/avatars/thumbs/` (the `-think` image for each character named, e.g. `av-01-judge-think.webp`) and paste the line. Start with the first 20; that's enough to switch Caption This to pictures.
