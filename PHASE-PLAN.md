# NOGGIN development phases

1. **Foundations:** Node/Express/Socket.IO server, LAN QR links, lobby, avatar choices, reconnects, shared CSS. Implemented.
2. **The board:** 36-space trapezium, dice, tokens, Start, Swap, Pickpocket, Brain Drain, Wildcard, Stage Lift, Sparks and win detection. Implemented.
3. **Speed and Brain:** all eight mini-games and starter question banks. Implemented.
4. **Create and Together:** all eight games, including drawing/guessing, anonymous votes and team challenges. Implemented.
5. **Showdowns + game-show polish:** four distinct corner Showdowns, closest-number Noggin-Off, Web Audio fallback, show effects and deployment templates. Implemented.
6. **Release preparation:** Windows/Render/Oracle installation walkthroughs; repaired NAT join throttling, underdog balance refinement, reproducible one-page How to Play PDF, release audit, GitHub CI recipe, browser and simulator reruns. Implemented with explicit unverified deployment tasks.

**Next, outside the six implementation phases:** full human/device QA, editorial review of facts, UX/accessibility refinements, and live deployment proving the environment and WebSockets. See `RELEASE-CHECKLIST.md`.
